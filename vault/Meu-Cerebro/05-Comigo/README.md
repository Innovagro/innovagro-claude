# 05-Comigo

**O que tem aqui:** `como-trabalhar-comigo.md` — como você gosta das coisas. Toda correção
que você dá a um agente ("não me manda tabela", "cliente X só por telefone") vem pra cá.

**Por que existe:** é o que faz os agentes melhorarem toda semana. Todo agente lê esta página
ao começar a trabalhar com você. É a memória deles sobre você — e fica com **você**.

**Regra:** é só seu. Nenhum agente copia isto pra outro lugar.
