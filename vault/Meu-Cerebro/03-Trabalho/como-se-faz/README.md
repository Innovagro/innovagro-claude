# como-se-faz

**O que tem aqui:** um procedimento por página, do jeito que é feito de verdade, não do jeito
do manual. Os passos, as exceções e o que costuma dar errado.

**Por que existe:** em toda área tem um procedimento que só uma pessoa sabe fazer. Se ela sai
de férias, o trabalho para. Esta pasta existe pra isso não acontecer.

Exemplo — `aprovar-pagamento.md`: os passos, quem aprova cada um, e o que costuma dar errado
("se faltar o documento X, volta pro solicitante antes de seguir").
