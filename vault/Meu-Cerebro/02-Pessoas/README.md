# 02-Pessoas

**O que tem aqui:** uma página por pessoa com quem você trabalha — de dentro ou de fora da
empresa. O papel dela, **o que ela decide** e como falar com ela.

**Por que existe:** o fecha-dia precisa saber quem é quem pra montar as listas de "espera
resposta minha" e "espero de alguém". E é o que mais se esquece.

**Quem escreve:** o agente, no fecha-dia, a partir do que você contou.

Exemplo — `nome-sobrenome.md`:
```
# Nome Sobrenome
Responsável pela logística do fornecedor X.
**Decide:** quando a carga sai e qual transportadora vai.
**Não decide:** preço do frete (é o gerente dele).
**Como falar:** responde rápido no Teams; por e-mail demora.
```
