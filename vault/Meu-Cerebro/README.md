# Meu Cérebro

Este é o seu cérebro de trabalho. **Você não precisa preencher nada.**

Os seus agentes escrevem aqui por você: durante o dia, anotam o que você contou, decidiu ou
corrigiu. Às 17h, no **fecha meu dia**, organizam tudo nas pastas.

| Pasta | O que tem |
|---|---|
| `01-Diario` | O registro de cada dia, com o seu fecha-dia |
| `02-Pessoas` | Com quem você trabalha e o que cada um decide |
| `03-Trabalho` | Clientes, procedimentos e sistemas do seu dia |
| `04-Combinados` | O que você prometeu e o que te prometeram |
| `05-Comigo` | Como você gosta das coisas — a memória dos agentes sobre você |

**É seu.** Nada daqui é copiado pra outro lugar.
Se algo estiver errado, fale pro agente: "isso está errado, o certo é…". Ele corrige.
