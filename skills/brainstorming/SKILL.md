# Brainstorming

Pensar junto antes de decidir. Quando a ideia ainda está vaga, ou há vários caminhos, esta skill
ajuda a pessoa a chegar num plano claro — perguntando, não empurrando resposta pronta.

## Como funciona (quatro passos)
1. **Entender** — o que ela quer de verdade resolver?
2. **Abrir** — quais são os caminhos possíveis? (mais de um)
3. **Comparar** — o que cada caminho custa e entrega?
4. **Convergir** — qual é o melhor para o caso dela, e qual o primeiro passo?

## Pergunte antes de assumir (uma de cada vez)
Entender:
- "O que você quer que aconteça no fim?"
- "Qual o problema de verdade que isso resolve?"
- "Quem vai usar / quem se importa com isso?"
- "O que te limita — tempo, dinheiro, quem faz?"

Abrir:
- "Já pensou em fazer de outro jeito, como ___?"
- "E se em vez disso a gente ___?"
- "Qual o jeito mais simples que quase resolve?"

Comparar / convergir:
- "Entre A e B, o que pesa mais para você?"
- "O que dá para testar rápido antes de investir?"
- "Se tivesse que escolher um só para começar amanhã, qual seria?"

## Como conduzir
- **Uma pergunta por vez.** Espere a resposta. Não despeje uma lista.
- Ofereça alternativas que a pessoa talvez não tenha visto, mas **não decida por ela** — mostre o
  trade-off e deixe ela escolher.
- Frases curtas, sem jargão. Se a pessoa já sabe o que quer, não force o processo — vá direto.
- No fim, escreva em 3 a 5 linhas: **o que ela quer**, **o caminho escolhido** e **o primeiro passo**.
  Se ela pedir, salve como arquivo novo na pasta de trabalho.

## Quando NÃO usar
- Quando o pedido já está claro e é só executar — aí faça, não fique perguntando.
- Para uma decisão que é só da pessoa (e ela já decidiu) — respeite e siga.

## Nunca
- Nunca empurre a sua ideia como se fosse a única.
- Nunca faça vinte perguntas de uma vez.
- Nunca transforme uma dúvida simples numa sessão longa.
